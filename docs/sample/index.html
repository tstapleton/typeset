Find

Shared

Only models defined in a directory directly below the feature and used from another one. Each line runs from a model to a directory that uses it, and its number and thickness show how many files and models there use it. Subdirectories count as part of their top-level directory. Use within a model's own directory and anything at the feature root are left out. Where a line starts on a card doesn't refer to a particular row. Click a line, card or directory for details.

Directories

One box per directory directly below the feature. A line means the code or models in one directory use models declared in another. Its number and thickness show how many distinct models. In each box, defined counts the models declared there, shared counts those used from another directory, and external models used counts the models it uses from other directories. Click a line or box for the list.

Connections

Edges leave from the row that holds the reference. A dashed card outline means the model isn't exported. A tinted header with a count means that many other top-level directories use the model. Purple names are declared outside the feature (or are classes or functions).

Evidence

Facts read from the code, listed for comparison. Click a model to find it.
